# Індивідуальний план професійного розвитку

## 1. Опис проєкту
Навчальний проєкт з курсу «Вступ до спеціальності «ІТ: Професія майбутнього»» (лабораторна робота №4). Містить самооцінювання компетентностей, SWOT-аналіз і план професійного розвитку за роллю бізнес-аналітика.

## 2. Мета
Оцінити свої сильні й слабкі сторони та скласти план розвитку для старту кар'єри Junior Business Analyst.

## 3. Що містить репозиторій
- самооцінювання компетентностей;
- SWOT-аналіз;
- план розвитку на найближчий період;
- чернетка резюме.
